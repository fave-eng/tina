# Отчёт по проверке v28 — учебная грамматика Кристины

## Содержательные изменения

Переработаны 5 тем. Каждая имеет собственный педагогический ход: владение как две системы; there is/are как новое и известное в дискурсе; местоимения по синтаксической функции; артикли по определённости и исчисляемости; множественное число по орфографическим и морфологическим классам. Составлены оригинальные упражнения разных типов, с пояснением каждого ответа. Примеры написаны авторски, без копирования учебников Murphy или Бонк.

## Методические ограничения и честная оценка

- Для глубокой гарантии качества нужна рецензия преподавателя по каждому заданию, особенно там, где допустимы перефразирования. Автоматический проверяющий принимает зафиксированные правильные ответы; свободные варианты могут потребовать ручной проверки.
- Для каждого уровня теперь доступны два независимых набора заданий. На третьем повторе наборы начинают чередоваться: доработать генерацию дополнительных оригинальных вариантов в следующем этапе.
- Система сохранения результата использует существующие ID и старый код `app.js`. Он намеренно не переписывался, поэтому сохранение с реальным пользователем следует проверить после публикации.
- За одну итерацию невозможно ответственно переработать 110 учебных тем с индивидуальной методикой и ручной проверкой. Остальные темы отмечены в карте как ожидающие содержательной переработки.
