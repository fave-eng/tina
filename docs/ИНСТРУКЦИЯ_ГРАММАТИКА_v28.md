# ОГЭ-2027 — грамматика, этап 1 (v28)

## Важное: это не полная переработка всех 110 тем

В этой версии методически переписаны **5 тем**:

1. have got / has got — две разные грамматические системы владения и have как действие
2. There is / There are — введение новой информации против указания местонахождения известного предмета
3. Личные и притяжательные местоимения — выбор формы по синтаксической функции
4. Артикли a/an/the/нулевой — смысловая определённость, исчисляемость и звуки
5. Единственное и множественное число — орфографические модели, исключения, неисчисляемые существительные и согласование

Ранее углублённая тема **to be** (v18) не изменялась. Остальные 104 темы ещё не переработаны в индивидуальном режиме: см. `docs/АУДИТ_110_ТЕМ_v28.md`.

## Файлы для загрузки на GitHub Pages

Загрузи **только эти три файла**, сохранив каталоги:

- `index.html` — добавлены две новые ссылки, остальные подключения из локальной версии v27 оставлены
- `data/grammar-individual-v28.js` — содержимое пяти уроков и 36 упражнений для каждого
- `grammar-individual-v28.css` — схемы и адаптивное оформление

Файлы в папке `docs/` служат методическим отчётом и необязательны для публикации.

**Перед обновлением** сохрани копию текущего `index.html`. Не заменяй файлом из ZIP, если с момента v27 вручную менялись ссылки на скрипты: в таком случае лучше добавить в текущий файл **только две строки**:

В `<head>` после стилей v26:

```html
<link rel="stylesheet" href="grammar-individual-v28.css?v=28">
```

После строки подключения `data/oge27-grammar-additions-v26.js?v=26` (но до `app.js`):

```html
<script defer src="data/grammar-individual-v28.js?v=28"></script>
```

Остальные файлы, включая `app.js`, `cloud-sync.js`, `email35.js`, `journal.js`, и данные Supabase не меняются.

## Проверка после установки

1. Очисти кэш браузера для сайта.
2. Открой `index.html#/грамматика`.
3. Последовательно открой темы `have got / has got`, `There is / There are`, `Личные и притяжательные местоимения`, `Артикли...`, `Единственное и множественное число`.
4. Проверь, что появились отдельные пояснения и схемы. Выполни один уровень с неправильным ответом, затем выбери «Новые задания после разбора» — должны появиться **другие вопросы**.
5. Убедись, что старые результаты занятий, дневник, письмо №35 и облачный прогресс на месте.

## Что проверено в локальной сборке

- Все 110 записей остаются в каталоге при загрузке библиотеки v19, дополнений v26 и v28.
- Все пять замен берут **существующие заголовки**, без изменения ID, маршрутов и поля прогресса.
- В каждом из пяти уроков — 3 уровня, два набора по 6 разных заданий на уровень (всего 36 заданий на тему). Список уникален по формулировке.
- Альтернативные допустимые ответы из банка проходят ту же проверку, что и ответы ученицы.
- Структура 4 индивидуальных смысловых секций каждой темы загружается без ошибок JS.
- Отрисовка пяти страниц проверена в изолированном Chromium на 1366 и 390 пикселей, без горизонтального выхода всей страницы.

**Не проверено:** реальное сохранение в аккаунт Supabase после установки на опубликованном сайте, доступность этой сборки по конечному URL, отсутствие новых конфликтов с пользовательскими правками после v27. Это нужно проверить вручную на сайте Кристины.
