# Кристина · ОГЭ по английскому 2027
## Установка углублённого грамматического справочника v19

**Что решает:** в прежней версии большинство пунктов меню «Грамматика» открывали краткие карточки с 2 вопросами либо вообще не имели теории. v19 открывает **98 отдельных конспектов в 11 разделах**. «to be» использует уже подготовленную подробную версию v18; для остальных 97 тем — новые материалы.

### Установка

1. Сначала скачайте **резервную JSON-копию прогресса** в настройках сайта Кристины. Сохраните копию исходных файлов на компьютере.
2. Распакуйте архив с сохранением папки `data/`.
3. В корне сайта подготовки к ОГЭ замените **`index.html` и `app.js`**, затем добавьте **`grammar-reference-v19.css`**. Файл `grammar-reference-v18.css` тоже включён в ZIP как необходимая основа; замените его только если ранее не устанавливали v18 или хотите восстановить стандартный файл.
4. В папке `data/` добавьте **`grammar-reference-v19-data.js`** и **`grammar-reference-v19.js`**. Основа **`grammar-reference-v18.js`** тоже есть в архиве для совместимости с теми, кто ещё не установил v18. Не удаляйте остальные файлы `data/`.
5. Загрузите изменённые файлы на GitHub Pages вашего **сайта ОГЭ-2027**, дождитесь публикации и обновите страницу с очисткой кеша.
6. Откройте «Грамматика»: должно быть **98 подтем** и **98 подробных объяснений**. Проверьте `to be`, `Present Simple`, `Предлоги времени`, `Passive Voice: Present Perfect` и `Словообразование прилагательных`.

**Не делайте:** не очищайте localStorage, не создавайте новую учётную запись, не сбрасывайте progress в Supabase и не заменяйте `config.js`, `cloud-sync.js`, `journal.js`, `data/program.js` или файлы других учеников. Для этой установки SQL и Edge Functions не нужны.

### Как устроена тема

- **Смысл и сфера употребления**: что сообщает конструкция; не просто список маркеров.
- **Наглядная карта**: временная линия, стрелочная модель, шкала значений модальных глаголов, части слова или иллюстрация IN/ON/AT.
- **Формула** с ориентиром на подлежащее, сказуемое и контекст.
- **Сравнительная таблица** с двумя контрастными примерами, переводом и объяснением отличия.
- **Нюансы** и хотя бы одна конкретная типичная ошибка с исправлением; ключевые темы дополнены расширенными сопоставлениями.
- **Связь с ОГЭ**: грамматические формы, словообразование или письмо/устная речь в зависимости от темы. Оригинальные упражнения созданы для тренировки навыков, а не взяты из реальных экзаменационных вариантов.
- **Три уровня**: ученица вводит ответы сама, получает разбор, при ошибках возвращается к правилу и получает другую подборку. Переход на новый уровень только после **6/6** в текущей подборке. Для 97 новых тем в каждом уровне банк из **12 заданий**, для `to be` — отдельный углублённый банк.
- **Повторение**: после трёх уровней доступна повторная проверка; рекомендуемый срок 14 дней. В 29-недельной программе сохранены прежние двухнедельные повторения.

### Как трактовать оценку

Результат 100% означает отсутствие ошибок **в предъявленных автопроверяемых упражнениях**. Это не доказывает абсолютного владения английской грамматикой. Для открытого перевода есть множество верных формулировок; система поддерживает некоторые распространённые сокращения, но не умеет надёжно оценить **любую** допустимую перефразировку. Если ответ по смыслу и грамматике верен, а сайт его отклоняет, проверяйте такой случай с преподавателем, а не заучивайте единственную фразу как обязательную.

Разделы **произношения и интонации** отнесены к практике устной речи, а не к письменным заданиям 20–34. Их полная проверка требует слушания и устной работы с преподавателем; этот архив не добавляет автоматическую оценку голоса.

### Что сохраняется

`app.js` продолжает пользоваться прежним ключом состояния `state.grammar[id].referenceV18` для прогресса справочника. Данные не очищаются и не мигрируют в другую таблицу. **История прежних попыток сохранится**; старые ручные отметки «Изучено» остаются в истории, но **не считаются** успешным прохождением трёх новых ступеней. Проверку живой облачной синхронизации необходимо выполнить после установки под аккаунтом Кристины.
