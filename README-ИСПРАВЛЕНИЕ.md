# Исправление редактирования письменных ответов · версия 8

## Как установить
1. НЕ сбрасывайте прогресс, не очищайте данные браузера и не импортируйте пустой JSON.
2. Скачайте резервную копию через «Настройки» на устройстве Кристины.
3. Замените только **app.js**, **cloud-sync.js** и **index.html** на действующем сайте, сохранив старый адрес сайта.
4. Обновите страницу. Если видна старая версия, сделайте обычное обновление с очисткой кэша страницы (не данных сайта).
5. Откройте «Мои занятия → Неделя 1 → Занятие 1», измените или полностью удалите прежний письменный ответ, введите новую версию и проверьте её после выхода со страницы и возвращения.
6. Если Кристина вошла в аккаунт Supabase, дождитесь подтверждения синхронизации в «Настройках». Повторно зайдите на страницу и проверьте новый текст.

## Что исправлено
- Раньше объединение черновиков сравнивало их **по длине**. Старое длинное предложение возвращалось после сокращения/редактирования.
- Теперь используется **время последнего изменения**. Более новый черновик побеждает независимо от длины, даже пустой.
- Введены даты редактирования для каждого ответа и отдельного письма.
- Фоновая облачная синхронизация больше не перерисовывает текстовое поле в момент ввода.
- Существующие сохранённые слова, занятия, результаты диагностики и старые черновики не удаляются.

## Ограничения
- Программа не может восстановить текст, который уже был утрачен на устройстве и в облаке.
- Для облачной проверки требуется настоящий вход в Supabase; тесты в браузере могут моделировать сервер, но не заменяют проверку на аккаунте ученицы.
- Если редактировать один и тот же ответ одновременно на двух устройствах, приоритет определяется временем последнего изменения на каждом устройстве; часы устройств должны быть установлены правильно.
