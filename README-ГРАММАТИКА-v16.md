# Кристина · ОГЭ по английскому 2027 · грамматика v16

## Перед установкой
1. Обязательно открой сайт Кристины → **Настройки** → **Скачать JSON-копию прогресса**. Сохрани файл вне папки сайта. Не очищай localStorage, cookies или данные сайта.
2. Используй **уже установленную версию 15** (и остальные файлы проекта); этот ZIP — только обновление, а не полный сайт.
3. Распакуй ZIP в корень сайта. Замени: `index.html`, `app.js`, `study.css`, `data/lessons.js`. **Добавь** новый файл `data/grammar-visual-mastery.js`. Не удаляй остальные папки и файлы, в том числе `cloud-sync.js`, `config.js`, `data/grammar-masterclass.js`, `data/reading-library.js`, `viewer.html`.
4. Обнови страницу в браузере. Не используй «Очистить данные сайта».
5. Открой **Неделя 1 → Занятие 1**: должна появиться сравнительная таблица конструкций *be/have got*, новый блок «Проверь, действительно ли правило усвоено» и тематический контроль.
6. Проверь **Неделя 3 → Занятие 1** (Present Simple vs Present Continuous): должна появиться двухполосная схема времени и сравнительная таблица.
7. Проверь **Неделя 23 → Занятие 1** (in/on/at): три наглядные карточки с примерами и исключениями.
8. Выполни один учебный ответ и проверь его сохранение после перехода на другую страницу и обратно. Убедись, что в «Настройках» подтверждена синхронизация с Supabase.

## Изменения
- 29 отдельных сравнительных таблиц и смысловых визуальных схем для 29 недель. Они связаны с полными авторскими объяснениями v15 и примерами, а не заменяют их.
- Для времён введены наглядные временные линии и сопоставление формы, отрицания, вопроса и ситуаций употребления; для предлогов — собственная памятка IN / ON / AT с «внутри / поверхность / точка».
- Объяснения нюансов и исключений встроены рядом с таблицами. Каждое сравнение завершается проверкой понимания.
- Новая адаптивная практика: 3 уровня, по 3 автоматически проверяемых вопроса на уровне. Для перехода нужен результат **3/3** на каждой ступени. После ошибки показаны правильный ответ и конкретное правило; можно вернуться к теории и получить новые задания из подготовленного банка.
- В подготовленном банке предусмотрено как минимум две разные последовательности из 3 вопросов на каждой ступени каждой недели; при исчерпании банка вопросы могут повторяться для закрепления. **Бесконечная генерация новых упражнений не заявляется**.
- Повторение после 14 дней с момента освоения темы. Сохранены 14 двухнедельных контрольных повторений из v15, для них теперь также ориентир **100%**, а не 75%.
- Для новых грамматических занятий зачёт требует 100% основных контрольных вопросов, прохождения всех 3 адаптивных ступеней и выполнения письменной части. Прежние завершённые занятия и старые оценки не пересчитываются.
- Первые семь недель получили более последовательные тематические вопросы вместо прежних заданий, забегавших вперёд программы. В более поздних неделях контроль включает также вопросы для накопительного повторения **ранее** пройденных правил.
- Новый набор ответов в обязательных грамматических заданиях сохраняется в `sessionAnswers` под отдельным ключом `...-quiz-v16`. Старые ответы и предыдущие попытки остаются в JSON и в истории.
- Прогресс новой практики сохраняется в поле `grammarMastery` того же JSON и синхронизируется как часть существующего облачного состояния. Новых таблиц Supabase для этого обновления не требуется.

## Важно о проверке
**100%** означает 100% верных ответов в конкретных автоматически проверяемых заданиях. Это **не доказательство полного владения языком**. Свободные предложения и письмо следует проверять преподавателю; сайт не может автоматически засчитать все допустимые варианты текста.

## Тестирование
Проверено в изолированном Chromium без обращения к реальному аккаунту: все 29 страниц грамматических занятий, сохранение черновиков при переходах, неправильные ответы и их разбор, выдача других вопросов после ошибки, последовательное прохождение уровней 1→2→3 со 100%, завершение первого занятия при наличии 100% в контроле и письменного ответа, а также мобильная вёрстка на ширине 390px. Проверен исходный JS-синтаксис Node и размер всех 29 банков заданий. Работа с настоящим Supabase-аккаунтом Кристины **не тестировалась**: проверь статус облака после установки.
