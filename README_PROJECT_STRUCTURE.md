# ОГЭ 2027 · Кристина · финальная структура

## Публикация

Публикуйте только `OGE_2027_Kristina_FINAL_SITE.zip` или обновление `OGE_2027_Kristina_FINAL_PATCH.zip`.
Они содержат `index.html`, файлы `.js`/`.css` и обязательные каталоги `data/` и `assets/`.

Не публикуйте `.git/`, `tests/`, `docs/`, `archive/`, `supabase/`, секреты, личные данные.

## Исходный проект

`supabase/` — инфраструктурные файлы, SQL и Edge Functions; `tests/` — тесты; `.git/` — исходная история.
Располагаются в отдельном приватном архиве `OGE_2027_Kristina_FINAL_PROJECT.zip`.

## Сохранность данных

Идентификатор Кристины `kristina-oge-2027`, ключ `kristina-oge-2027-state-v1`,
`config.js` и `cloud-sync.js` оставлены без изменений. Публикация не удаляет базу Supabase.
Нужно предварительно экспортировать прогресс на устройстве Кристины через Настройки.
Нельзя очищать локальное хранилище браузера, сбрасывать аккаунт или запускать миграции без проверки.

Новый зачёт недели: 3 зачтённых занятия + письмо не короче 90 слов,
отправленное в Supabase. Три отдельных учебных дня рекомендованы, но не обязательны.

## Облачный статус

В подключённом Supabase-проекте существуют таблицы прогресса, писем и истории писем.
Активные функции `kristina-oge-alerts`, `kristina-oge-diary-review`, `kristina-oge-diary-reminder`, `oge-email35-review` были обнаружены;
`kristina-oge-reports` пока не развернута и для неё требуется отдельное развёртывание и создание таблицы доставок.
Никакие серверные изменения не были автоматически применены.

ВНИМАНИЕ ПО БЕЗОПАСНОСТИ: две таблицы `public.progress_legacy_backup` и `public.legacy_progress_snapshots`
имеют выключенный RLS в живом Supabase. Проверьте, нужны ли к ним доступы anon/authenticated,
затем отдельно согласуйте и настройте политики перед включением RLS. Это не исправляется заменой ZIP сайта.

Версия индивидуального модуля грамматики — v28 (имеющаяся в `tina.zip`). Архивы v29 из предыдущего
разговора недоступны для чтения как исходные байты и не были выданы за включённые в релиз.
