# Исправление сохранения упражнений, версия 9

Замени на существующем сайте **только** файлы `app.js` и `index.html`. Остальные файлы и база Supabase не меняются. Не удаляй данные браузера.

Причина: в версии 8 выбор вариантов теста хранился лишь в оперативной памяти страницы, а текст ответа — в локальном хранилище. После перезагрузки страницы ответы исчезали, и при проверке выводилось «0 из 18».

Что исправлено:
- Каждый выбранный вариант сохраняется в `localStorage`, а затем синхронизируется с Supabase, если выполнен вход.
- Выбор сохраняется после перезагрузки, ухода со страницы, фоновой синхронизации.
- Текст письменного ответа, результаты теста и ранее изученные темы не удаляются.
- При неполном занятии сайт сообщает точное число сохранённых ответов и прокручивает к первому пропущенному вопросу.
- По кнопке «Повторить упражнения» ответы сбрасываются намеренно, ранее зачтённое занятие не обнуляется.
- После замены нужно обновить страницу (при необходимости Ctrl+Shift+R) и проверить счётчик.

ВАЖНО: Если варианты были выбраны только в прежней версии и уже исчезли из памяти страницы, восстановить именно эти варианты из старых JSON нельзя. Письменный текст должен сохраниться, если он уже был записан. Для проверки сейчас можно выбрать по одному варианту в двух вопросах, обновить страницу и убедиться, что счётчик показывает 2 из 18 и кнопки остаются выбранными. Затем продолжить тест.

Перед заменой сохрани JSON через «Настройки» — «Скачать копию прогресса». Файлы приложения при обновлении не стирают данные, но резервная копия позволит вернуть данные при иных сбоях.

Никаких SQL миграций не нужно: новые поля размещаются в уже используемом JSON-снимке `oge_student_state`.

## Как не повторять уже проверенную попытку
Если в Supabase уже есть полный журнал предыдущей попытки (18 вопросов, не менее 70%), но она не зачтена только из-за объёма текста, после дополнения текста до 55 слов появится кнопка «Зачесть ранее проверенную попытку ... без повторения вопросов». Сайт берёт результат из фактического журнала, не восстанавливает и не выдумывает старые выбранные варианты. Такую попытку можно зачесть без повторного решения теста.
