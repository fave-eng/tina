# Кристина — перенос результатов и просмотр для семьи

Изменения версии 6: в кабинете наблюдателя добавлены готовые недельный и месячный отчёты, проверка записи в Supabase после синхронизации, безопасная дополнительная локальная копия до первого объединения и обновление кэша сайта. Ранее: активирована защищённая синхронизация в Supabase-проекте «общий», добавлен одноразовый код доступа для наблюдателя и отдельная страница `viewer.html`. Данные других учеников и их таблицы не изменялись.

## Самое важное: как не потерять старый тест

1. **Не удалять прежние файлы и не очищать браузер Кристины.** Результат может сохраняться в `localStorage` только по старому адресу сайта и в прежнем браузере.
2. На том же компьютере и **на том же адресе** открыть старый сайт. Зайти в «Настройки» и скачать JSON «Резервная копия». Если результат диагностики уже виден — особенно важно сохранить его.
3. Установить файлы из этого ZIP на **тот же HTTPS-адрес**, заменяя файлы в существующей папке сайта и сохраняя остальные материалы. При смене адреса или файлового пути старый `localStorage` может оказаться недоступным. Если старый сайт запускался из `file://`, лучше восстановить JSON на опубликованном сайте, чем надеяться на перенос браузерного хранилища.
4. Если на новом сайте нет старых результатов — в «Настройках» нажать «Восстановить из файла» и выбрать сохранённый JSON. Убедиться, что тест появился.
5. На компьютере Кристины открыть «Настройки», создать **её личную** учётную запись Supabase (или войти), подтвердить email, если запрошено. Нажать «Синхронизировать». Дождаться отметки «Прогресс сохранён в облаке» и времени последнего сохранения. Только после этого проверять доступ с другого устройства.
6. В кабинете Кристины нажать «Открыть доступ для семьи». Сгенерированный код действует 72 часа, используется один раз. Передать код только наблюдателю.
7. Открыть `viewer.html` на опубликованном сайте с другого компьютера. Создать **отдельную** учётную запись наблюдателя, войти и ввести код. Результаты после этого доступны только для просмотра. Можно нажать «Обновить»; при открытой вкладке данные обновляются также автоматически раз в 2 минуты.

**Если старые ответы вообще не сохранились в исходном браузере и резервной JSON-копии нет, восстановить их с нашей стороны невозможно.** Никакого удалённого доступа к компьютеру Кристины у сайта нет.

## Что синхронизируется

Диагностика и отдельные ответы, уроки и зачтённые занятия, учебные дни, словарь, грамматика, неправильные глаголы, письменные черновики, журнал попыток и ошибок. После первого входа старая браузерная запись и облачная запись объединяются (если имеют правильный studentId). Наблюдатель может читать результаты, но не изменять их.

## Права доступа

- Supabase-проект: `общий` (ref `zqzgarvmpqqqaobeicpc`).
- Таблицы с RLS: `oge_student_state`, `oge_report_events`, `oge_student_viewers`, `oge_share_invites`. Созданы в проекте заранее; заново запускать SQL не требуется.
- Код приглашения генерируется на сервере, привязывает один аккаунт наблюдателя к аккаунту ученицы, а затем становится недействительным.
- У Кристины есть кнопка «Закрыть доступ наблюдателям», которая отключает всех наблюдателей (можно снова создать код позже).
- Токены Telegram и ключ `service_role` не используются в браузере. В `config.js` находится только публичный ключ Supabase, предназначенный для клиентского кода.
- **Telegram-отчёты пока не активированы**, несмотря на готовую облачную запись событий. Нужно отдельно развернуть Edge Function и расписание.

## Условия и ограничения

- Для нормальной работы нужен опубликованный HTTPS-сайт, не просто копия ZIP на разных компьютерах.
- Подтверждение email и возможность регистрации зависят от настроек Supabase Auth; если регистрация недоступна, необходимо настроить её в панели проекта.
- Нельзя гарантировать, что предыдущий результат уже существует: без первого входа Кристины таблицы пустые.
- Упражнения и словарь остались из предыдущей версии; данное обновление относится к сохранению и просмотру данных.

## Внимание: что ещё НЕ включено

Автоматическая отправка сообщений в Telegram по расписанию не была подключена и не проверялась, поскольку необходимо отдельно настроить серверную функцию, секрет бота и расписание. На странице наблюдателя отчёты доступны сразу после появления синхронизированных данных (их можно копировать).

Этот ZIP **не переносит данные автоматически через компьютер без участия Кристины**. Для переноса нужно обновить страницу по тому же адресу, где сохранены ответы, войти в аккаунт Кристины и подтвердить строку «Прогресс сохранён в облаке».
