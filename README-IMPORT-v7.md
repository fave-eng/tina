# Исправление: безопасное облачное сохранение (версия 7)

1. Сохрани обе исходные JSON-копии и не очищай данные браузера.
2. На том же адресе сайта замени в корне `index.html`, `app.js` и `cloud-sync.js`. Остальные файлы оставь как есть.
3. **Обнови страницу с очисткой кэша**. В «Настройки» создай аккаунт Кристины (или войди), подтверди почту при необходимости и нажми «Синхронизировать». Дождись явного подтверждения облака.
4. В поле «Восстановить объединённый прогресс с телефона и компьютера» введи секретный одноразовый код из отдельного файла. Нажми «Привязать сохранённый прогресс». Сайт объединит прогресс, сохранит его в защищённой записи аккаунта и проверит чтение обратно.
5. Проверь 37 слов, 35 глаголов, 2 темы грамматики и историю. Изученные темы могут дополняться новыми занятиями.
6. Только **после подтверждения облака** Кристина начинает стартовый тест. Ответы сохраняются после каждого выбора; при завершении результат проверяется в Supabase, а файл JSON автоматически скачивается. Если появляется предупреждение — остановись и сохрани JSON.
7. Для просмотра с другого аккаунта Кристина создаёт код «Открыть доступ для семьи», а наблюдатель вводит его в `viewer.html`.

Примечания: копия загрузилась в закрытую staging-таблицу Supabase, но ещё не закреплена за аккаунтом. Ученический сайт пока не опубликован через инструменты ChatGPT. Реальная проверка login → claim → diagnostic в браузере Кристины ещё не проходила; без успешного входа нельзя обещать облачное сохранение.
