2. Тестовая отправка в Telegram

Отправляет одно настоящее сообщение в тему группы. Этот шаг не входит в обычную диагностику.

Сначала проверь соединение и подтверди отправку.

3. Если сообщение не приходит

Сверяй настройки с результатами выше. Не присылай скриншоты секретных ключей и токенов.

Ошибка Failed to send a request to the Edge Function часто означает блокировку запроса браузером из-за CORS. В Edge Function в Access-Control-Allow-Headers должен присутствовать x-client-info наряду с authorization, apikey и content-type.
Если запрос доходит до функции, но Telegram возвращает chat not found или message thread not found, нужно проверить числовые ID группы и темы. Число в конце Telegram-ссылки не всегда является ID темы.

Страница специально не отображает API-ключи, пароли, токены и содержимое дневника. Копирование результата включает только диагностические статусы.
