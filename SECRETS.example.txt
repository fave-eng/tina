Supabase Dashboard → Edge Functions → Secrets:

OGE_TELEGRAM_BOT_TOKEN = существующий секретный токен вашего бота
OGE_REPORT_CHAT_ID = настоящий числовой chat.id супергруппы (не определять только по ссылке t.me/c)
OGE_REPORT_THREAD_ID = настоящий числовой message_thread_id нужной темы
OGE_REPORT_CRON_SECRET = длинная случайная строка (использовать точно ту же в Vault)
OGE_REPORT_STUDENT_USER_ID = (необязательно) UUID аккаунта Кристины, если в базе несколько записей с тем же studentId

SUPABASE_URL и SUPABASE_SERVICE_ROLE_KEY обычно выдаются платформой Supabase Edge Functions автоматически.
SERVICE_ROLE_KEY ни при каких условиях не размещать в файлах веб-сайта.
