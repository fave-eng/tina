# Кристина · ОГЭ-2027 · обновление учебной логики v11

## Как обновить сайт

Это **архив для замены изменённых файлов** в уже опубликованном кабинете Кристины версии 10. Он не содержит и не заменяет базу Supabase, секреты, настройки бота, конфигурацию ученицы или другие учебные данные.

1. На текущем сайте Кристины открой «Настройки» и **экспортируй JSON с прогрессом**. Сохрани его отдельно, не импортируй поверх текущих данных.
2. На хостинге или в папке сайта замени строго следующие пути:
   - `index.html`
   - `app.js`
   - `study.css`
   - `data/personalized-study.js` (новый файл, должен лежать в существующей папке `data`)
3. **Не удаляй** существующие `data/program.js`, `data/lessons.js`, `data/lesson-theory.js`, `config.js`, `cloud-sync.js` и остальные файлы. Не удаляй данные в браузере.
4. Перезагрузи страницу, открой `Мои занятия → Неделя 1 → Занятие 1`. Проверь наличие словаря из 12 слов и четырёх вопросов мини-теста.
5. Проверь в «Настройках» статус Supabase и выполни ручную синхронизацию. На компьютере Кристины убедись, что её старые результаты и текст сохранились.
6. Открой `Повторение → Дополнительные задания по слабым темам`. Если ранее было не менее двух ошибок по одной теме, появится тренировка; иначе раздел пока пуст.

## Что добавлено

- На **каждом** из 87 учебных экранов: лексика дня (12 единиц), отметки изучения, произношение, мини-тест на 4 слова, отдельное правило/подсказка по грамматике и характерным ошибкам.
- Письменные задания предлагают использовать слова из словаря дня. Текст по-прежнему проверяется по объёму, а не автоматически по языковым критериям.
- После проверки учебного теста показаны выбранный и правильный ответы, объяснения, название темы; этот разбор сохраняется между перезагрузками.
- Анализ повторяющихся ошибок: от 2 неправильных ответов по одной конкретной теме. В разделе «Дополнительные задания» появляются тематические мини-тесты из нового дополнительного банка, если банк по этой теме уже подготовлен. Успешное завершение убирает тему из очереди до новых ошибок.
- Для темы без отдельного набора пока показываются её название, число ошибок и ссылка на персональный разбор прежних вопросов. Это **не** полноценная генерация новых заданий для всех возможных ошибок.
- Добавленные тренировочные ответы и аналитика включены в обычное локальное и облачное сохранение.

## Важно

- Старые попытки, зачтённые занятия, словарь и диагностика **не сбрасываются этим обновлением**. Автоматический сброс/миграция не включены.
- Добавленные словарные мини-тесты и адаптивная практика учитываются отдельно; они не меняют старый результат и не заменяют три обязательных дня занятий.
- Часть исходных вопросов прежних недель всё ещё повторяется и не везде строго посвящена одной грамматической теме. Требуется дальнейшая педагогическая редактура банка из 29 недель. Это обновление не заявляется как 87 полностью уникальных комплектов заданий.
- Автоматическая проверка свободного текста или устного ответа по критериям ОГЭ отсутствует.
- Telegram-отчёты этим обновлением не подключаются; для них нужна отдельная настройка сервера.
