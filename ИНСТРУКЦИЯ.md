# ОГЭ 2027 — полная диагностика v20

## Для чего

Страница `diagnostics.html` проверяет:

1. Что она открыта из каталога именно сайта «Мой ОГЭ · 2027», а не другого сайта ученицы Kristina / English Space.
2. Основные файлы программы, уроков, стартовой диагностики и отчётов.
3. Подключение **98 тем грамматики v19**.
4. Файлы чтения, словаря и **дневника v17**, наличие ссылки на дневник в главной странице.
5. Возможность использования localStorage — без удаления или замены прогресса.
6. Публичную конфигурацию Supabase, доступность сети, реальную серверную авторизацию в текущем браузере.
7. Возможность прочитать именно свою облачную запись прогресса и историю дневника (содержимое не выводится в отчёт).
8. Доступность функций `kristina-oge-diary-reminder`, `kristina-oge-diary-review`, `kristina-oge-alerts`.
9. CORS/POST Telegram **без отправки сообщения**.

Дополнительно, **только после нажатия соответствующей кнопки**, можно:

- Проверить запись даты посещения через `oge_mark_visit` (это изменяет только время последнего посещения, не ответы и не оценки).
- Отправить один настоящий Telegram-тест, чтобы подтвердить связь с конкретным чатом и темой.
- Проверить AI-разбор сегодняшней записи (возможен расход средств API OpenAI; текст не попадает в копируемый отчёт).

## Установка

1. В «Настройках» сайта предварительно скачайте резервную JSON-копию прогресса.
2. Найдите GitHub Pages-репозиторий **того сайта, где заголовок «Мой ОГЭ · 2027»**. Не путайте с репозиторием Kristina / English Space — это другое приложение.
3. Загрузите **только** `diagnostics.html` **рядом с** файлом `index.html` сайта ОГЭ. Если старый `diagnostics.html` уже есть, замените именно его.
4. Дождитесь публикации GitHub Pages. Откройте адрес сайта ОГЭ, заменив в конце `index.html` на `diagnostics.html`. Например, если главная открывается по `https://example.github.io/<папка>/index.html`, диагностика будет по `https://example.github.io/<папка>/diagnostics.html`.
5. Нажмите «Проверить всё». Выполните это на том же телефоне и в том же браузере, где Кристина пользуется сайтом. Затем повторите на компьютере.
6. Если строка «Вход в аккаунт» жёлтая, откройте главную страницу → «Настройки» → войдите в аккаунт Кристины, затем повторите диагностику. Не удаляйте локальные данные до резервного копирования.
7. Нажмите «Скопировать отчёт» и пришлите его в чат для разбора. Отчёт не включает учётные данные, записи дневника и ответы ученицы.

## Расписание Telegram в 21:00

Наличие активной Edge Function **не означает**, что она автоматически запускается. Сайт не может безопасно посмотреть секреты сервера и список задач `pg_cron`.

При предыдущей серверной проверке расширения `pg_cron` и `pg_net` **не были установлены**. Это подтверждённый блокер для предложенной ранее схемы расписания через Supabase cron. Чтобы проверить заново, откройте **Supabase → SQL Editor** и выполните безопасный запрос чтения:

```sql
select extname, extversion
from pg_extension
where extname in ('pg_cron', 'pg_net');
```

Если обе строки появились, тогда можно проверить список задач (запрос чтения; не вставляйте никакие секреты в текст отчёта):

```sql
select jobid, jobname, schedule, active
from cron.job
where jobname ilike '%oge%' or jobname ilike '%kristina%';
```

**Если `pg_cron` не установлен, второй запрос запускать не нужно.**

Ежедневное напоминание на **21:00 по Уфе** соответствует **16:00 UTC**. Но нужно также проверить, что реальная задача cron активна, вызывает нужную Edge Function и использует верный секрет. Успех ручного Telegram-теста не доказывает работу расписания.

## Что нельзя подтвердить одной страницей

- Фактическое облачное сохранение и восстановление **на втором устройстве**. Проверяйте после резервной копии, без очистки браузера, на двух устройствах с одной учётной записью.
- Содержательную правильность всех 98 грамматических объяснений и ответов. Диагностика проверяет наличие и загрузку файлов, а не педагогическую экспертизу каждого задания.
- Доставку ежедневного сообщения **без реального Telegram-теста и проверки cron**.
- Доступность OpenAI API без отправки реальной записи; это можно сделать только отдельной подтверждённой кнопкой.

## Безопасность

Страница не читает и не отправляет токены на чужие серверы; использует публичную конфигурацию текущего сайта. В копируемом отчёте — только обезличенные статусы и коды ошибок. Никакие пароли и API-ключи не вставляйте на страницу.
