# ОГЭ 2027 · v23 · дневник на компьютере

Исправление только навигации сайта «Мой ОГЭ · 2027»; не для другого сайта Kristina / English Space.

## Что было
В компьютерной версии `app.js` пункт «Мой дневник» находился 9-м в боковой панели, которая прокручивается независимо. В обновлении v22 домашняя карточка дневника отображалась только на телефоне: CSS явно скрывал её на широких экранах.

## Что меняется
- «Мой дневник» становится первым пунктом бокового меню компьютера.
- Появляется кнопка «Мой дневник» в верхней панели компьютера.
- Карточка дневника доступна на главной и на компьютере, и на телефоне.
- Работает после перерисовки страниц, без обновления данных ученицы.
- Переход ведёт на существующий `index.html#/дневник`.

## Как установить

**Рекомендуемый вариант, если на сайте уже установлен объединённый v22:**
1. Сохрани текущий `index.html` на компьютер.
2. Загрузи в корневую папку сайта два новых файла: `desktop-diary-v23.js` и `desktop-diary-v23.css`.
3. Добавь в `<head>` существующего `index.html` две строки (если их там ещё нет):

```html
<link rel="stylesheet" href="desktop-diary-v23.css?v=23">
<script defer src="desktop-diary-v23.js?v=23"></script>
```

Рекомендуется поместить CSS после `mobile-navigation.css`, а JS после `mobile-navigation.js`. Файлы должны находиться в корне сайта рядом с `index.html`.

**Альтернативно:** если исходный `index.html` не менялся со времени v22, можно заменить его готовым `index.html` из архива. Если менялся, **не заменяй целиком**, добавь только две строки по инструкции.

4. После публикации открой сайт Кристины на компьютере, сделай обновление без кеша (`Ctrl+Shift+R` Windows или `Cmd+Shift+R` Mac), либо открой в приватном окне.
5. Проверь «Мой дневник» первым в левом меню, рядом с настройками в верхней панели и карточку на главной.
6. Открой `index.html#/дневник`: дневник должен загрузиться. Если нет, запусти `diagnostics.html`.

## Сохранность данных
Это обновление не содержит и не заменяет `app.js`, `journal.js`, `cloud-sync.js`, `config.js`, файлы уроков и базу Supabase. Оно не изменяет сохранённые записи и не отправляет уведомления.

## Границы проверки
Синтаксис JS проверен через Node.js. Логика перемещения ссылки, создания кнопки, карточки и повторной инициализации проверена отдельным тестом. Извлечь URL реального опубликованного сайта из сообщения не удалось, поэтому фактический результат на компьютере Кристины нужно проверить после установки.
